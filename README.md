## Featured Projects

### 1. QuickServe — DevOps Engineering & AWS Deployment

A containerized web application used to demonstrate DevOps workflows, automated image delivery, and AWS-based deployment.

**Key implementation highlights:**
- Automated CI/CD workflows using GitHub Actions.
- Docker image build and publishing to GitHub Container Registry (GHCR).
- GitHub Actions authentication with AWS using OpenID Connect (OIDC).
- IAM role-based access and AWS Systems Manager (SSM).
- Automated container deployment and application verification on an AWS EC2 instance.
- Separate local Kubernetes and Helm practice.

**Technologies:** Docker, GitHub Actions, GHCR, AWS EC2, IAM, OIDC, SSM, Linux, NGINX, Kubernetes, Helm.

**Links:** [Source Code](https://github.com/GitWithKomal/QuickServe) · [Live Application](https://gitwithkomal.github.io/QuickServe/) · [GitHub Actions](https://github.com/GitWithKomal/QuickServe/actions) · [AWS Deployment Run](https://github.com/GitWithKomal/QuickServe/actions/runs/42997207347)

## Run Locally

Clone the repository:

```bash
git clone https://github.com/GitWithKomal/komal-portfolio.git
cd komal-portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Create a production build:

```bash
npm run build
```
