## Featured Projects

### Veyra

Cloud-native roadside assistance and mechanic booking platform with location-aware mechanic discovery, role-based workflows, and real-time service notifications.

**Technologies:** React, Vite, Tailwind CSS, Node.js, Express, MongoDB Atlas, Mappls, Socket.IO, Docker, GitHub Actions, Render, Vercel

### DockMind AI

AI-powered document intelligence application using retrieval-augmented generation to answer questions from uploaded PDF documents.

**Technologies:** React, Vite, Tailwind CSS, Node.js, Express, Gemini API, LangChain, RAG, embeddings, MongoDB Atlas Vector Search

Dynamic emergency vehicle route planning system combining geospatial services, backend routing logic, and a web-based interface for emergency navigation.

**Technologies:** React, Vite, Flask, Mappls APIs, Docker, GitHub Actions, Render

Full-stack personal finance and habit management application with authentication, financial tracking, and administrative analytics.

**Technologies:** React, Tailwind CSS, Node.js, MongoDB, JWT, Recharts
